# Classroom PDF → Markdown

Userscript для Tampermonkey: рядом с каждым PDF-вложением в Google Classroom появляется кнопка **MD**. Клик скачивает файл из Drive под твоей сессией, вытаскивает текст и сохраняет его как `.md`.

Без API-ключей, без сервера, без установки Python-зависимостей — всё в браузере.

## Установка

1. Поставь [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Firefox).
2. Открой панель Tampermonkey → **+** (новый скрипт).
3. Скопируй туда содержимое `classroom-pdf-to-md.user.js` и сохрани (Ctrl+S).
   Либо перетащи сам файл `.user.js` в окно браузера — Tampermonkey предложит установку.
4. Обнови страницу Classroom.

## Как пользоваться

1. Открой курс → материал или задание, где прикреплён PDF.
2. Рядом с названием файла будет маленькая кнопка **MD**.
3. Нажми её. Кнопка покажет `···`, потом `✓` — браузер скачает `<имя файла>.md`.
4. Если что-то не так — `!`/красная кнопка и тост с причиной в правом нижнем углу.

Файл начинается с YAML-шапки:

```yaml
---
title: "Лекция 3. Графы и деревья"
source: "https://drive.google.com/file/d/…/view"
converted: 2026-11-05
---
```

## Что делает с текстом

- строки собираются по базовой линии, слова — по горизонтальным зазорам;
- двухколоночная вёрстка распознаётся и читается по колонкам (левая, потом правая);
- заголовки — по размеру шрифта относительно основного текста (`#`, `##`, `###`), жирные короткие строки тоже считаются заголовками;
- абзацы склеиваются по вертикальному ритму, переносы через дефис (`гидро-` + `динамика`) склеиваются в слово;
- списки: `•`/`—`/`*` → `-`, `1)`/`1.` → `1.`;
- выкидываются номера страниц и повторяющиеся колонтитулы (3+ страницы).

## Ограничения

- **Сканы и фото страниц не поддерживаются**: если в PDF нет текстового слоя, кнопка скажет об этом. OCR не подключён.
- Картинки, формулы, диаграммы и сложные таблицы в `.md` не попадают — только текст и простая структура.
- Если преподаватель запретил скачивание файла, Drive вернёт заглушку — будет ошибка «файл закрыт для скачивания».
- pdf.js грузится с jsDelivr (`pdfjs-dist@3.11.174`) через `@require`: нужен интернет при первом запуске после установки.

## Проверка без Classroom

`dev.html` — локальная страница с тем же конвертером:

- открой `dev.html` в браузере;
- перетащи PDF — увидишь готовый Markdown и сможешь скачать/скопировать;
- внизу макет вложения Classroom: там проверяется сама кнопка `MD` (клик по фейковой ссылке должен дать ошибку в тосте — так и задумано).

## Если кнопка не появилась

- Скрипт срабатывает только на `https://classroom.google.com/*`.
- Вложение должно быть файлом Drive (`drive.google.com/file/d/…`). Ссылки на сторонние сайты, YouTube и Google Forms не обрабатываются.
- Classroom — SPA: скрипт пересканирует страницу каждые 2 секунды, но после перехода может понадобиться секунда.
- Ошибки пишутся в консоль с префиксом `[Classroom PDF→MD]`.
